Tiles v0.4 arcade UI refresh + bug-fix source update

Included changes:
- Replaced the in-game music file with the trimmed loop-ready MP3 (removed trailing silence/gap).
- Refreshed the UI styling to feel much more like a retro arcade game:
  - brighter gold/pixel-style buttons
  - more saturated neon/glow treatment
  - stronger logo treatment
  - more game-like landing page panels and menu visuals
  - upgraded arena/panel styling
- Added a Leave Room button.
- Leave Room now sends a websocket leave-room message so the room seat is freed immediately.
- The 'is choosing...' overlay now uses the player NAME instead of their color.
- Improved mobile responsiveness / safe-area spacing and stacked small-screen layouts.
- Updated tile-fall rendering so dropped tiles become holes rather than leaving the 3D side wall visible.
- Added more glow/shadow life to the board and power-up presentation.

Files changed:
- public/audio/retro-arcade-theme.mp3
