# Tiles V0.3 locked gameplay specification

- 2–5 players, private room codes, no accounts.
- Hexagonal arena with side length 3 = 19 cells.
- Six floor colors: red, orange, yellow, green, blue, violet.
- Board color arrangement regenerates every round with bounded randomness.
- Tap/click any reachable tile; server computes the path.
- One player per logical tile.
- Approximately 7 seconds of movement; no permanent visible timer.
- Moving avatars can collide; glancing impacts are brief, direct head-on impacts receive a longer stumble/sidestep penalty.
- Collision commitment prevents last-instant course cancellation at about 300 ms before impact.
- Selector wheel uses surviving/eligible player colors and the capped-repeat fairness system.
- Selector chooses one floor color after positions lock.
- Selected color gets a 1.15 second reveal/crack window before collapse.
- One life per match; eliminated players spectate.
- Last survivor earns one session trophy.
- Room tracks session wins and supports rapid rematches.
- 0–2 physical power-ups may spawn; first avatar to physically reach the cell gets the item.
- Maximum one held power-up.
- V0.3 runtime currently includes Speed and rare Phase Shift from the functional V0.2 core; the visual/UI architecture is prepared for additional power-ups after balance testing.
- Phase Shift may be activated during the 1.15 second reveal window and moves the threatened player to a random safe unoccupied tile.
- Player identities use five non-repeating character colors: yellow, blue, red, green, pink.
